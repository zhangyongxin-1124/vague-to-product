# 3 分钟安装演示视频 · 分镜脚本

> 用途：交付给视频制作者（或用录屏软件照着念）即可产出"小白上手三件套"里的安装视频。全长目标 3-3.5 分钟，配字幕，语速平缓。

## 分镜 1 · 开场（0:00-0:20）

画面：桌面空白 → 弹出一句话"我想做个闹钟 App"。
口播：装了这个技能，AI 不会直接乱写，也不会把你问烦——它会一层层问清需求，然后把成品交给你。今天 3 分钟装好它。

## 分镜 2 · 第 0 步：装 Python（0:20-1:00）

画面（录屏）：python.org 下载页 → 安装向导 → **特写圈红"Add Python to PATH"** → cmd 里 `python --version` 出版本号。
口播：先装 Python，记得勾选最下面这个 PATH 选项，然后验证一下，能看到版本号就对了。

## 分镜 3 · 第 1 步：下载解压（1:00-1:30）

画面（录屏）：GitHub Releases 页 → 下载 ZIP → 解压到 F 盘文件夹。
口播：去 Releases 下载最新版，解压到你找得到的地方。顺便核对页面上的 SHA256 更安心（进阶，可跳过）。

## 分镜 4 · 第 2 步：放进 WorkBuddy（1:30-2:10）

画面（录屏）：复制文件夹到 `C:\Users\你\.workbuddy\skills\` → 重启 WorkBuddy。
口播：把整个文件夹复制进 skills 目录，重启。用 Codex 的朋友一样道理，复制到 .codex\skills；用网页版 AI 的，把使用说明里的系统提示词粘进对话就行（能力有降级，画面出三档对比表 2 秒）。

## 分镜 5 · 第 3 步：验证（2:10-2:40）

画面（录屏）：新对话输入"我想做一个帮老人找零工的 App"→ AI 回复形态判定+深度评分+带选项的第一轮问题。
口播：装没装好，看一件事——AI 是不是先给带选项的问题。像这样就是成功了。

## 分镜 6 · 排错与结尾（2:40-3:10）

画面：命令行跑 `python scripts/selftest.py` 全绿 → FAQ 页面一闪 → Issues 页面。
口播：有问题先跑自测，再翻 FAQ；还不行去 Issues 提一条。三分钟，从此 AI 交付有底线。地址在评论区。

## 制作备注

- 全程 1080p，文字特写停留 ≥3 秒；关键路径打字幕。
- 片尾固定帧：GitHub 仓库地址 + "MIT · 张勇鑫"。
