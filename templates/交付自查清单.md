# 交付自查清单（你要怎么自己验证）

> 用途：每次交付时，AI 依铁律 21 必须按本模板生成一页"你要怎么自己验证"，让用户拿到成品后知道怎么核对，而不是凭感觉信任 AI。用户也可对照本卡手动检查 AI 是否偷工减料。
> 使用：复制骨架 → 按形态勾选 → 每条必须写"具体动作 + 预期结果"，禁止写"请自行检查"。

## 一、通用部分（所有形态必填）

| # | 检查项 | 具体动作 | 预期结果 | 结果（□/✓） |
|---|---|---|---|---|
| 1 | 交付物与说明一致 | 按"我做了什么/没做什么"逐条核对实物 | 无虚报、无"此处略" | |
| 2 | 验收标准逐条过 | 对状态矩阵/P0 验收逐行动手验证 | 每行有 ✓ 或问题记录 | |
| 3 | 假设核对 | 核对"默认假设"清单与现实是否相反 | 无被违反的假设 | |
| 4 | 合规档位 | 查看合规流程报告档位与"上架/经营前必须办理"清单 | 知道下一步办什么 | |
| 5 | 数字核实 | 报告中的数字（成本/工期/法规）抽 2 条去官方源核对 | 与官方一致或已记录差异 | |

## 二、按形态追加（选对应形态的一行执行）

- **软件（App/网页/小程序）**：6. 装得起来：按说明构建/运行成功；7. 空态与极端量：清空数据、断网、超大输入各试一次；8. 关键流程走通：注册→核心功能→退出全程无报错。
- **文档**：6. 结构完整：目录、章节、结论齐全；7. 事实抽查：抽 3 处引用/数据核对来源；8. 机密核对：敏感信息只出现在约定版本。
- **表格**：6. 公式抽查：改 2 个输入格看结果联动；7. 极端量：0、负数、超大值不报错；8. 口径一致：合计=分项之和。
- **图形/3D**：6. 规格核对：尺寸/分辨率/配色符合约定；7. 可用格式：文件能在目标工具打开。
- **音视频**：6. 时长与规格核对；7. 关键帧抽看/抽听无瑕疵。
- **实物/经营**：6. 证照清单逐项向官方窗口核实；7. 数字抽查：客流/毛利用实测数据。
