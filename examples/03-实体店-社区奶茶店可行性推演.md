# 案例 03【演示】社区奶茶店：实体/经营类推演

> 性质：**演示性推演案例**——按真实需求类型（实体店经营）整理，用于展示方法与输出形态，不是真实交付记录。

## 输入

用户原话：**"我想在小区门口开家奶茶店。"**

## 挖掘要点（D4，实体类）

- 形态判定：实物/经营（非软件）；五信号：影响半径 4（押上身家）、不可逆性 4（装修+租约）、未知量 4（客流、竞争、证照）、复杂度 3、复用性 1 → D4，分批深挖。
- 关键追问：
  1. 为什么是奶茶？看到什么让你觉得这个小区缺奶茶店？（行为回溯，验证是真需求还是臆想）
  2. 预算上限与退出条件？亏到多少收手？
  3. 加盟还是自营？配方与供应链从哪来？
  4. 你自己顶店还是雇人？——决定人力成本模型。

## 伪需求体检（节选）

- "小区缺奶茶店"≠"小区的人会买我的奶茶"——要求用户拿出工作日晚 8-10 点的实地人流计数，而不是感觉。
- 外卖平台抽成后单价还成立吗？——要求按 3 个价格带重算毛利。

## 红线与办证（合规收口，黄灯）

| 类别 | 清单 |
|---|---|
| 证照 | 营业执照、食品经营许可证、从业人员健康证 |
| 消防与环保 | 消防验收/备案、油烟与噪声（居民楼底商重点） |
| 签约 | 房租租约条款（免租期、转让费）、加盟合同审查 |
| 营销红线 | 促销不得虚构原价、会员卡预付资金规则 |

## 倒排周计划（摘要）

W1-2 实地验证与人流计数 → W3-4 竞品定价与毛利模型 → W5-6 证照办理（提前期最长）→ W7-8 选址签约 → W9-12 装修与供应链 → W13 试营业。

## 你要怎么自己验证

1. 人流计数是否有至少 3 个不同时段的实测数据；
2. 毛利模型是否用了实际进货报价而非网络均价；
3. 证照清单是否逐项向当地市监/消防窗口核实过提前期。
