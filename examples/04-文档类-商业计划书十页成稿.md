# 案例 04【演示】商业计划书：文档类十页成稿

> 性质：**演示性推演案例**——按真实需求类型（文档创作）整理，用于展示方法与输出形态，不是真实交付记录。

## 输入

用户原话：**"帮我把我的想法写成一份商业计划书。"**

## 挖掘要点（D3，文档类）

- 形态判定：文档；五信号：影响半径 3（给投资人看）、不可逆性 1、未知量 3（读者是谁、篇幅、用途）、复杂度 2、复用性 2 → D3。
- 关键追问：
  1. 这份 BP 给谁看？种子投资人 / 银行贷款 / 合作伙伴？（决定结构与口径）
  2. 十页还是三十页？路演用还是细读用？
  3. 哪些数字是实、哪些是估？——估的必须标注口径，禁止冒充实数。
  4. 不写什么？——商业机密（定价模型、渠道名单）不进精简版。

## 分批产出（D3 分批铁律）

| 批次 | 产出 |
|---|---|
| 批次 1（≤3 轮） | 阶段产出 A：方向说明 + 十页目录骨架（用户确认口径） |
| 批次 2（≤3 轮） | 阶段产出 B：核心四章成稿（问题/方案/市场/财务框架） |
| 批次 3 | 终稿 + 附录 + 阶段产出 C：路演合规提示（不泄露商业机密版清单） |

## 交付质量要点

- 每页一个论点，标题即结论（投资人 90 秒扫一页）；
- 财务测算三张表口径一致，估算值全部带标注；
- 附"你要怎么自己验证"：数字是否对得上自己的账、机密是否只出现在可控制版本。

## 你要怎么自己验证

1. 十页每页标题连读是否就是完整故事线；
2. 所有估算数字是否标了口径与假设；
3. 发送前用"机密清单"逐页核对没有敏感信息外泄。
