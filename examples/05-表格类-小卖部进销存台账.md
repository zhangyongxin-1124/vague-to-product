# 案例 05【演示】小卖部进销存台账：表格类快速通道

> 性质：**演示性推演案例**——按真实需求类型（表格工具）整理，用于展示方法与输出形态，不是真实交付记录。

## 输入

用户原话：**"给我做个记账表。"**

## 挖掘要点（D1，表格类快速通道）

- 形态判定：表格；五信号：影响半径 1、不可逆性 1、未知量 1、复杂度 1、复用性 2 → D1，**只问一轮**。
- 唯一一轮（4 题带选项）：
  1. 记什么账？家庭开销 / 小店进销存 / 项目报销？
  2. 谁在什么设备上用？手机单机 / 电脑多人？
  3. 要自动算什么？余额、分类小计、月度对比？
  4. 不做什么？——不做自动同步、不做报表导出（V1 边界）。

## 产出（两轮内交付成品表）

| 工作表 | 内容 |
|---|---|
| 进货 | 日期、品名、数量、进价、供应商 |
| 销售 | 日期、品名、数量、售价、收款方式 |
| 库存 | 自动汇总：期初 + 进 − 销 = 现存，低于安全库存标红 |
| 月报 | 自动小计：毛利、分类占比、环比 |

## 交付说明（三句话）

- 这是什么：一个打开即用的 Excel 台账，四个工作表已填示例数据；
- 第一步点什么：清空"进货/销售"两张表的示例行，从今天开始记；
- 我没做什么：没有公式保护锁定（怕你不会改），没有多端同步。

## 你要怎么自己验证

1. 改一笔进货数量，库存表对应行是否自动变化；
2. 把销售数量改超过库存，是否出现负数警示（空态与极端量检查）；
3. 月报毛利是否等于销售收入 − 对应销货成本（口径核对）。
