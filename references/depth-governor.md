# 深度调节器（Depth Governor）

> **核心命题：挖掘轮次不是常量，是变量。**
> 问三轮就收，对「帮我起个文件名」是浪费；对「做一个涉钱的平台」是失职。
> 所以本工具不问「该问几轮」，只问三个问题：**影响多大 / 改起来多贵 / 你有多不知道**。

---

## 1. 五个信号（0–2 分，合计 0–10）

| 信号 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **影响半径** impact | 只影响自己 | 影响少数他人（客户/同事） | 影响公众 / 涉及钱 / 涉及法律 |
| **不可逆性** reversi | 改起来便宜（草稿/原型） | 改动有成本（已给人看过） | 改不动（已发布/已投产/已开模/已签约） |
| **未知量** unknown | 用户很清楚要什么 | 部分模糊，说得清场景说不清做法 | 用户自己也不知道，只有感觉 |
| **复杂度** complex | 单一静态产出 | 多部件/多素材/多来源 | 交互系统/多角色/多约束联动 |
| **复用性** reuse | 一次性，用完就丢 | 自用，会反复用 | 给别人用 / 要卖 / 要长期维护 |

**打分原则**：就高不就低，但必须能说出依据。说不出依据的高分是保守，不是谨慎——保守会让你多问十轮，用户会烦。

### 怎么问出这三个关键分（不用直接问，要侧面问）

| 要判的 | 别直接问 | 改问 |
|---|---|---|
| 影响半径 | 「这东西影响多大？」 | 「做出来给谁看？除你之外还有谁会用？」 |
| 不可逆性 | 「改起来贵不贵？」 | 「最晚什么时候必须定下来？定下来之后还能改吗？」 |
| 未知量 | 「你想清楚了吗？」 | 「你心里有参考的样子吗？能说出它像什么吗？」 |

## 2. 五级深度

| 级别 | 分数 | 轮次预算 | 做法 | 典型场景 |
|---|---|---|---|---|
| **D0 直达** | 0–1 | 1 | 不问，直接做一版，让用户看着改 | 改个文件名、调个颜色、生成一条文案 |
| **D1 标准** | 2–3 | 2 | 定位 + 必挖点，一遍问完 | 自用的小工具、内部一页纸通知 |
| **D2 深挖** | 4–5 | 3–5 | 加对象层与质量层 | 要交给客户的文档、要给别人用的小程序 |
| **D3 深度** | 6–7 | 5–8 | 加约束层与演化层，逐项验风险 | 涉钱、涉合规、要考虑后续维护 |
| **D4 分层深挖** | 8–10 | 8–∞ | **分批推进**：每 3 轮出一次阶段产出，验收后再继续 | 用户完全没想清 + 高风险 + 复合需求 |

### D4 的特殊规则（这是唯一不限轮次的一级）

D4 不能一口气问 12 轮——没人受得了。必须**分批**：

```
批次 1（3 轮）→ 出阶段产出 A（如：一页纸方向说明 / 3 个方案对比）
   用户看到 A，通常会说出真正在意的东西
批次 2（3 轮）→ 出阶段产出 B（如：完整规格 / 可点原型）
   用户改 B 时暴露的，才是真实约束
批次 3（余下）→ 定稿
```

**判据**：每批结束必须有**可看的东西**。连续两批没有产出，说明不是深挖，是拖。

## 3. 什么时候该升级（往上加轮次）

出现以下任一情况，**立刻重算分数并升级**，不要按原计划收敛：

1. 用户答出了一个原假设里没有的人群（「其实主要是给外包人员用」）
2. 出现了钱（收费、分成、垫付、押金）
3. 出现了第三方（要给别人用、要公开、要上架）
4. 出现了不可逆动作（要印刷、要开模、要报名、要签约）
5. 用户开始自相矛盾（前面说自用，后面说卖给客户）
6. 用户否定了你给的默认假设，且否定理由是「我们这行不是这样」

> 第 6 条最容易被忽略。用户说「不是这样」时，说明**整个推演的前提错了**，不是某个细节错了。

---

## 4. 什么时候该收敛（停止追问）

四条判据，满足**任一**即可停，不必全部满足：

### 4.1 信息饱和
本轮新获得的有效约束 < 2 条。用户的回答开始重复前面说过的意思。

### 4.2 必挖点覆盖完成
该形态要求的必挖维度（见 `output-forms.md`）全部问到了。用 `v2p route` 的「覆盖预演」可以直接看。

### 4.3 边际递减
最近两轮问的维度，答案没有改变任何一个 P0 / 内容清单 / 交付形态。**问了不改方案，就是白问。**

### 4.4 用户疲劳（最重要的信号）
- 回答从整句变成词（「嗯」「对」「都行」）
- 出现「你看着办」「差不多就行」「你比我懂」
- 开始回答上一个问题（没在读了）

**一旦出现 4.4，立即停止提问**，把没问到的转为「默认假设清单」，直接产出，并在交付时明说：「这 3 处我按 X 处理了，不对你说一声我改。」

> 疲劳状态下继续问，得到的是**假数据**。假数据比没数据更危险，因为它看起来像需求。

### 4.5 用户直接叫停
「别问了，直接做」「先给我个东西看看」——**立即降到 D0/D1**，做一版，让他对着实物说。

---

## 5. 降级也是合法动作

深度不是只能往上加。以下情况**主动降级**并说明：

| 情况 | 动作 |
|---|---|
| 用户叫停 | 降到 D0，先出东西 |
| 发现这是试验性质（「先试试，不行就算了」） | 降到 D1，明确说「先做最小版，别投入太多」 |
| 用户答不出关键问题且明显焦虑 | 降一级，把该问题转为默认假设 |
| 你要问的第 N 轮，答案不会改变产出 | 直接砍掉这一轮 |

**降级时必须说清代价**：「按 D1 做，我会按默认假设处理 A/B/C 三处，返工概率约 X 成。」——把选择权和风险一起交回去。

## 6. 自检（每轮结束跑一遍，30 秒）

```
□ 这一轮有 2 条以上新约束吗？        没有 → 该收敛了
□ 这一轮问的维度，和上一轮不同吗？      相同 → 换维度，别追问同一件事
□ 我现在能一句话说清「给谁、什么场景、靠什么动作」吗？  能 → 可以定型
□ 用户最近一次回答，比上一次长还是短？   变短 → 疲劳，准备收
□ 我下一轮要问的，会改变产出吗？        不会 → 砍掉
```

---

## 7. 和旧版（固定三轮）的区别

| 项 | 固定三轮 | 深度调节器 |
|---|---|---|
| 轮次 | 永远 3 轮 | 1–∞，由信号决定 |
| 问题 | 同一套，谁都问 | 按形态取题，文档不问「核心动作」 |
| 深浅 | 无法表达「这事很复杂」 | D0–D4 五级，可升可降 |
| 停止 | 问完三轮就停（可能没问透） | 四条饱和判据，问透才停 |
| 记录 | 无 | 记深度习惯，下次从舒适区起步 |
