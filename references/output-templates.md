# 输出模板（按深度变体，v2.7.0 细则下沉）

> 主文档只保留各级骨架摘要；本文件是完整对话与产出模板。

## D0（不问）

```
【直接做了】这是什么 + 怎么用 + 我替你决定的 2 处
```

## D1（2 轮）

```
【形态与深度】doc · D1 · 2 轮
【三处歧义 + 默认假设】
【第 1 轮 4 题】→ 【第 2 轮 4 题】→
【定型】一句话 + 必须包含的内容 + 不做什么
【产出】直接交
```

## D2（3–5 轮）

```
【形态与深度】… D2 · 3–5 轮 · 覆盖预演 ✓
【歧义 + 默认假设】
【逐轮提问，每轮报「本轮覆盖了哪个维度、下一轮问什么」】
【定型】产出定型卡 / PRD
【回读确认】
【产出 + 自检】
【沉淀】偏好 / 否决项 / 深度
```

## D3–D4（5 轮以上，分批）

```
【批次 1（≤3 轮）】→ 出阶段产出 A（方向说明 / 方案对比）
　　↓ 用户看到 A 后通常会说真实约束
【批次 2（≤3 轮）】→ 出阶段产出 B（完整规格 / 可看原型）
【批次 3（余下）】→ 定稿
【终局交付】阶段产出 B：最终产品（必交，不论可否上架）
　　　　　　→ 阶段产出 C：合规流程报告（后续怎么走、怎么安排）
```

## 分批纪律

- 每批必须有可看的东西。**连续两批没产出 = 在拖，不是在挖。**
- **阶段产出 A/B/C 是里程碑编号，不是终点**：任何批次结束后，流程的终点只能是 7.4 的两件套（最终产品 + 合规流程报告）。
- 批次之间用户插新需求 → 走 `v2p change` 自动重跑红线 diff 与工期推演，不要口头答应。
