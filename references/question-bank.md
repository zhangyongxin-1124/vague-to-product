# 问题库（按形态 × 维度）

> 用法：从这里挑题，不要现编。**先按形态找，再按维度挑。**
> 一轮最多 4 题，同一维度最多 2 题。
> CLI 已内置 56 题：`v2p ask --form doc --depth D2 --round 2`
> 本文件是它的可读版 + 扩充区（CLI 里的题库见 `scripts/v2p.py` 的 `FORM_Q`）。

---

## 0. 通用四题（所有形态第一轮都用这四支）

| 维度 | 问题 | 为什么必问 |
|---|---|---|
| 目标 | 这东西做出来，你第一件事要拿它干嘛？ | 决定分量：自用 vs 卖，成本差 10 倍 |
| 场景 | 上一次你需要这东西，是什么时候？怎么解决的？ | 决定真假：说不出具体场景，多半是伪需求 |
| 交付 | 最终交给谁、以什么方式交？ | 决定形态：自己用 vs 公开发布，要求完全不同 |
| 约束 | 什么时候必须拿到？ | 决定深度：今天要就只能 D0/D1 |

选项化写法（直接抄）：

```
A. 自己用，解决自己的麻烦        代价：零成本可先做
B. 给一个具体的人用              代价：要问清他的习惯
C. 给客户/合作方用              代价：要能对外展示
D. 卖给一批人（要商业化）        代价：需资质+运营，成本最高
E. 存档备查，不一定有人用        代价：按规范做，别过度设计
```

## 1. 软件应用 app（必挖：对象·质量·边界）

### 对象层
- 它最核心的那**一个**动作是什么？（记录 / 查 / 算 / 看状态 / 发出去 / 匹配两方）
  > 能说出两个核心动作，说明是两个产品。
- 数据最终存在哪里、谁能看到？（本机 / 跨设备 / 多人 / 长期留存）
- 谁维护它？（自己改文件 / 要管理页 / 一次做完不动 / 自动跑）

### 质量层
- 什么程度算「能用」？（3 步内走完 / 手机上能点 / 断网能用 / 能导出）

### 边界层
- 明确不要什么？（不要登录 / 不要支付 / 不要协作 / 不要推送 / 不要后台）

### 场景层 / 演化层
- 在什么场景下打开？（电脑前久坐 / 手机边走边用 / 当人面演示 / 每天批量处理）
- 以后会不会加人、加数据、加功能？（只我用 / 两三人 / 持续加 / 要卖）

---

## 2. 文档与报告 doc（必挖：对象·质量·边界）

### 对象层
- **读者读完要做什么决定或动作？**（批预算 / 签字 / 投资 / 照着执行 / 存档）
  > 这一题比「给谁看」重要得多。给谁看只决定语气，做什么决定决定全部结构。
- 读者最想知道的那一件事？（能不能做 / 花多少 / 风险 / 怎么做 / 为什么是它）
- 篇幅与深度？（1 页 / 3–5 页 / 10 页以上 / 越全越好）

### 质量层
- 什么算过关？（能直接签字 / 能过评审 / 能拿去讲 / 自己看得懂）

### 约束层
- 有没有必须遵守的模板、口径或术语？（我给模板 / 按行业惯例 / 要引用权威来源 / 没有）

### 交付层
- 以什么形式交？（Word 可打印 / PDF 发人 / PPT 讲 / 在线文档协作）

### 边界层
- 哪些内容绝对不能写进去？（未核实数字 / 内部成本 / 点名 / 承诺性表述 / 无限制）

---

## 3. 表格与数据 sheet（必挖：对象·质量·约束）

- **这张表一行代表什么？**（一笔收支 / 一个人 / 一个项目 / 一天 / 一个 SKU）
  > 不定这题，后面每个公式都会返工。
- 要算出哪些数？（合计 / 占比 / 同比 / 排名 / 不用算）
- 数据从哪来、怎么进表？（手工填 / 导出粘贴 / 别人填 / 自动同步）
- 谁看这张表、看什么？（自己看总数 / 老板看趋势 / 会计要对平 / 客户看明细）
- 数据量级？（几十 / 几百 / 上万 / 不确定）
- 结构以后要不要改？（列固定 / 要加列 / 多表关联 / 别人用不能改坏）
- 最终要什么？（能填的 xlsx / 能打印的报表 / 可导入的 CSV / 模板+说明）

---

## 4. 图形与图像 visual（必挖：对象·质量·交付）

- **这张图用在哪？**（手机竖屏 / PPT 横版 / 印刷海报 / 头像图标 / 产品界面）
  > 用途与尺寸一起问。分开问会得到自相矛盾的答案。
- 风格参照哪一个？（极简黑白 / 国潮 / 科技深色 / 手绘插画 / 按我的参考图）
- 要不要可编辑？（只要图片 / 要能改字 / 要分层源文件 / 要做成模板）
- 有没有不能出现的元素？（真人照片 / 品牌色字体 / 二维码 / 某几种字体 / 无限制）
- 这次要几张？（1 张试向 / 3–5 张一组 / 成套 10 张以上 / 印刷成品文件）
- 画面必须出现哪些信息？（一个主标题 / 标题+说明 / 加联系方式 / 是一组数据）

---

## 5. 3D 模型与空间 model3d（必挖：对象·质量·交付）

- **这个模型拿去干什么？**（看 / 渲染 / 3D 打印 / 进引擎 / 开模）
  > 用途决定拓扑。这题不问就开做，八成交付时不能用。
- 尺寸和比例有依据吗？（有图我给 / 按场景估 / 要放进某个空间 / 无所谓）
- 做到什么程度？（白模 / 带材质贴图 / 要能动 / 照片级渲染）
- 哪些部分不能改？（外形尺寸固定 / 接口固定 / 只要外观 / 保留品牌元素 / 无限制）
- 要什么文件？（STL/3MF / OBJ/FBX / STEP/IGES / 只要渲染图）
- 你用什么软件打开它？（不知道 / Blender / CAD / 切片软件）

---

## 6. 音视频 media（必挖：对象·质量·边界）

- **在哪放、给谁看？**（抖音竖屏 / B 站横屏 / 内部培训 / 展会循环）
  > 平台与时长一起定。先定「要 3 分钟」再做内容，是常见的顺序错误。
- 多长？（15–30 秒 / 1 分钟 / 3 分钟 / 10 分钟以上）
- 手上有哪些素材？（有脚本 / 有素材没脚本 / 什么都没有 / 只有参考片）
- 什么算能交？（不丢人 / 带转化 / 过平台审核 / 内部看懂）
- 不能出现什么？（真人 / 未授权音乐字体 / 承诺效果 / 某品牌竞品 / 无限制）
- 要什么交付？（成片 MP4 / 分镜脚本+提示词 / 配音稿+字幕 / 素材包）

## 7. 资料与知识 material（必挖：对象·边界·演化）

- 给谁用、解决什么问题？（自己查 / 教别人 / 给客户 / 存档备查）
- 资料从哪来？（自己写的 / 网上收集 / 纸质扫描 / 别人给的乱文件）
- 按什么结构组织？（主题 / 时间 / 项目客户 / FAQ 式）
- 怎么算好用？（3 秒找到 / 新人能自学 / 能对外发布 / 自己不丢）
- 有没有不能公开的内容？（内部信息 / 个人信息 / 他人版权 / 都可公开）
- **以后谁维护、多久更新？**（只有我 / 团队负责 / 定期更新 / 一次做完不动）
  > 这题不问，建完就死。是资料类最大的失败点。

---

## 8. 实物与服务 physical（必挖：对象·约束·质量）

- 最终交什么？（样品 / 小批量 / 量产 / 一场活动 / 一套 SOP）
- **数量级多少？**（1 件 / 10–100 / 1000 以上 / 先不算）
  > 不问数量就报价等于瞎报。工艺路线在数量级确定前无法选。
- 有没有硬约束？（图纸场地 / 预算区间 / 交期死线 / 都没有）
- 什么算合格？（通过强制认证 / 客户验收 / 自己能卖 / 先看效果）
- 哪些不能碰？（食品接触 / 儿童用品 / 改结构 / 新增供应商 / 无限制）
- 要什么交付物？（BOM+图纸 / 实物样品 / 执行方案 / 供应商对比表）

---

## 9. 未定形态 unknown（必挖：对象）

只有两题，但必须先答：

1. 你要的最终东西，最接近哪一类？（软件 / 文档 / 表格 / 图 / 3D / 音视频 / 资料 / 实物）
2. 它交出去以后，别人拿它干什么？（照着做 / 做决定 / 看效果 / 存着备用 / 自己看舒服）

> 第 2 题常常能反推出形态：要「照着做」的多半是文档或 SOP；要「看效果」的多半是图或视频。

## 10. 绝不问的题（黑名单）

| 不问 | 原因 | 改问 |
|---|---|---|
| 你的预算是多少？ | 开场劝退，他多半没算过 | 先给两档方案让他挑 |
| 要不要用 AI / 微服务 / 云原生？ | 技术选型不是需求 | 哪一步最花时间？ |
| 你觉得这个设计好吗？ | 抽象无法判断 | 给两个具体版本选 |
| 你要什么功能？ | 让他从零描述 | 从候选里砍 |
| 你的目标用户画像是什么？ | 人人答「所有人」 | 上次有谁跟你抱怨过这事？ |
| **这个项目要做几轮？** | 轮次由深度决定，不该问用户 | 直接按信号算，把预算告诉他 |
| **你能接受多深的挖掘？** | 用户无法判断 | 问具体事实，自己算深度 |

## 11. 怎么往库里加题

加题只改一处：`scripts/v2p.py` 里的 `FORM_Q`，格式：

```python
Q("object", "问题文本？", [
    ("选项A", "代价：……"),
    ("选项B", "代价：……"),
], rec=0, hint="可选提示", multi=False)
```

规则：
1. `dim` 必须是 8 个维度之一（`goal/scene/object/constraint/quality/boundary/delivery/evolution`）
2. 每题 3–5 个选项 + 自动追加「都不是，我自己填」
3. `rec` 指向推荐项下标，`-1` 表示不推荐
4. 加完跑 `python scripts/selftest.py`，确认 72 项仍全过
