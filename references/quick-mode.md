# 快速模式（急性子通道，v2.5.0 → v2.7.0 细则下沉）

> 主文档 SKILL.md 5.1 只保留触发条件与红线提醒；本文件是完整细则。

## 触发条件

用户明确说「少问点，直接做」「我很急」「别问了」时启用。**用户没说就不启用**——快速模式是用完整性换速度的自愿交易，不能替用户做这个决定。

## 执行细则（5 条）

1. **追问压缩到最少两轮**：第一轮只问必挖维度 + 边界（不做什么），第二轮确认默认假设；
2. **其余全部走「默认假设 + 若相反则……」兜底**，禁止再追加轮次——哪怕你发现新疑点，也写进假设清单而不是继续问；
3. **产出必须标注**：「快速模式产物：未经完整挖掘，假设清单见附录」。假设清单逐条=假设内容 + 若相反则怎么改；
4. **合规红线照常召回**（红线不因快速模式豁免），但合规报告可简化为清单式——红牌路线依然不能做，黄灯项写进"上架前必须办理清单"；
5. **交付后提醒**：如需正式版，可说「按完整流程重跑一遍」。

## 终局交付不豁免

快速模式**不豁免**铁律 19 的终局交付要求：该交的产品本体（含目标形态核对、设备匹配、呈现顺序三道关卡）一件不少，`scripts/gate_verify.py` 照常跑。快速的是"问"，不是"验"。
